Kebijakan Privasi

Terakhir diperbarui: 2 September 2026

Terima kasih telah menggunakan Pujangga POS. Kebijakan Privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, dan melindungi informasi Anda saat menggunakan aplikasi mobile Pujangga POS ("Aplikasi").

1. Pengumpulan dan Penggunaan Data

Pujangga POS dirancang sebagai aplikasi Point of Sale (Kasir) berbasis lokal. Semua data yang Anda masukkan ke dalam Aplikasi, termasuk namun tidak terbatas pada:

  • Data transaksi dan riwayat penjualan
  • Data produk atau katalog barang
  • Informasi pengaturan aplikasi

disimpan sepenuhnya secara lokal di perangkat Anda. Kami tidak mengumpulkan, mentransmisikan, atau menyimpan data ini di server kami.

2. Izin Aplikasi (App Permissions)

Aplikasi mungkin meminta izin tertentu di perangkat Anda untuk dapat berfungsi dengan baik (seperti akses penyimpanan atau kamera untuk scan barcode). Izin ini hanya digunakan untuk fitur di dalam aplikasi dan tidak digunakan untuk mengumpulkan data ke server eksternal.

3. Layanan Pihak Ketiga

Aplikasi ini mungkin menggunakan layanan analitik pihak ketiga atau layanan pelaporan error (seperti Firebase Crashlytics) semata-mata untuk mengidentifikasi bug dan meningkatkan performa aplikasi. Layanan tersebut dapat mengumpulkan data perangkat secara anonim.

4. Keamanan Data

Karena data Anda disimpan secara lokal, keamanan data bergantung pada keamanan fisik dan digital perangkat Anda. Kami menyarankan Anda untuk menggunakan fitur keamanan perangkat bawaan (seperti PIN, sidik jari, atau kata sandi) untuk melindungi data Anda.

5. Perubahan pada Kebijakan Privasi Ini

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Kami akan memberitahu Anda mengenai perubahan apapun dengan mengunggah Kebijakan Privasi yang baru di halaman ini. Anda disarankan untuk meninjau Kebijakan Privasi ini secara berkala untuk setiap perubahan.
